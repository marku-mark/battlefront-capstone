# LBC capability and flow matrix

Evidence checked 2026-10-24. Public facts are from the official pages in [the source audit](api-sources.md). “API unknown” means no implementable merchant contract or entitlement was verified; it does not mean LBC lacks the capability.

| LBC flow/capability                  | Public official evidence                                                                                                                                                                                                                                                      | Preparation consequence                                                                                                                                                                                                                       | Merchant API status                         |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| Shipment mode                        | LBC Online offers rider pickup or branch drop-off; Shipping Services describes both.                                                                                                                                                                                          | Represent sender handoff mode explicitly in future domain mapping. Existing Battlefront manual shipment handling is not the same as either LBC booking mode.                                                                                  | Unknown                                     |
| Booking details                      | Public booking flow collects sender, receiver, pickup/delivery, and package details.                                                                                                                                                                                          | Map required sender, recipient, origin, destination, and package inputs before designing any request. Determine which values Battlefront already has and which it lacks; minimize retained copies.                                            | API fields/schema unknown                   |
| Rate and serviceability              | Public calculator takes service type, origin/destination, product, weight, dimensions, declared value, and valuation fee. LBC Common API’s indexed description mentions first/last-mile serviceability and branch listings.                                                   | Battlefront’s current product handling profile, destination validation, and demo fee are not substitutes for LBC package dimensions/weight, LBC location identifiers, serviceability, rate, or valuation.                                     | Contract/entitlement unknown                |
| Shipping-fee payment                 | Public Shipping Services flow says select pay upon pickup or branch drop-off; E-commerce FAQs say sender settles shipping fees at transaction.                                                                                                                                | Separate customer checkout money from what Battlefront must pay LBC at handoff. Do not assume the customer delivery fee equals LBC’s final charge.                                                                                            | Merchant billing/settlement unknown         |
| Booking confirmation and identifiers | Public pages describe online booking and a tracking number; indexed Pick Up FAQ distinguishes booking number from tracking number. LBC Online help snippets describe confirmed online bookings receiving tracking numbers. These public descriptions vary by channel/version. | Model booking reference and carrier tracking/waybill as distinct concepts until the exact chosen merchant flow and identifier issuance are evidenced.                                                                                         | API contract unknown                        |
| Pickup/drop-off lifecycle            | Public flow proceeds from booking/details and payment choice to package preparation, rider collection or branch acceptance. Pickup FAQ search content says no same-day pickup for that public service and earliest dates depend on the page.                                  | Treat handoff acceptance as a real-world event, not the initial booking. Any pickup scheduling rules must be confirmed for the relevant merchant product.                                                                                     | State contract unknown                      |
| Tracking                             | Public tracker displays progress and LBC advertises real-time tracking; public page lists visible progress labels and email/SMS notifications.                                                                                                                                | LBC status vocabulary and event source should drive a future mapping after merchant documentation. Battlefront milestones cannot be treated as LBC’s native statuses.                                                                         | Polling/events/status semantics unknown     |
| LBC COD                              | LBC public COD describes LBC collecting the buyer amount and remitting it to the seller; shipping/valuation fees are separately paid by the sender at transaction.                                                                                                            | This is a carrier collection and seller settlement product, not merely Battlefront’s current “payment pending until admin confirms collection” state. Decide if/how Battlefront intends to use it and define reconciliation/accounting first. | API availability and merchant terms unknown |
| LBC COP                              | LBC public COP describes branch pickup, buyer payment at branch, then remittance to seller.                                                                                                                                                                                   | Separate from home delivery and from Battlefront store pickup. Do not infer support in the current one-shipment/order flow.                                                                                                                   | API availability and merchant terms unknown |
| Cancellation                         | No merchant cancellation/finality contract was verified.                                                                                                                                                                                                                      | Keep cancellation unresolved for any future real adapter; do not assume consumer booking cancellation behavior.                                                                                                                               | Unknown                                     |
| Webhooks/retries/errors              | Portal surfaced API names, but no usable operation contract was accessible.                                                                                                                                                                                                   | No guessed payloads, signatures, idempotency keys, polling intervals, rate limits, or retry rules.                                                                                                                                            | Unknown                                     |

The public flow guides domain discovery, but it does not establish that Battlefront can automate any step. See [open decisions](open-questions.md) for Battlefront policy and integration choices that remain to be made.
