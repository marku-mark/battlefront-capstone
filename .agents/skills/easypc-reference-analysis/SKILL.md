# Purpose

Compare publicly visible customer features with Battlefront needs using current, cited evidence. Recommend original Battlefront behavior; never copy proprietary code, images, text, or branding.

## Preconditions

- Read `AGENTS.md` and relevant product-scope context.
- Browse the current reference pages; do not rely on remembered layouts or search snippets.

## Workflow

1. Inspect `https://easypc.com.ph/`, `/pages/build-a-pc`, `/pages/build-your-pc`, and `/pages/easybuild`.
2. Record date, accessible page content, visible controls, product categories, and published claims.
3. Separate observed controls from marketing claims and from behaviors that require interactive verification.
4. Compare verified findings with Battlefront’s existing catalog, cart, saved-item, and checkout behavior.
5. Recommend accessible, original improvements and identify unavailable or unverified information.

## Expected output

Use a brief comparison with source links, observed evidence, limits, Battlefront implications, and recommendations. Label EasyPC save persistence, compatibility accuracy, checkout transfer, mobile behavior, or accessibility unverified unless directly tested.

## Safety and validation

Use public pages only. Do not sign in, submit purchases, scrape personal data, bypass access controls, or copy protected assets. Reopen each cited page and ensure the cited claim is directly supported. Treat competitor claims as claims, not proof of correctness.
